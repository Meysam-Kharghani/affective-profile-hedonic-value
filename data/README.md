# Data access

Raw participant-level data are not redistributed in this repository. Obtain EmoEEG-MC from OpenNeuro accession `ds005540`.

The behavioral-label reconstruction script operates on `sub-01` through `sub-53`. The core analysis uses one common complete-case exclusion for a missing liking value, resulting in 2,225 trials.

Imagery/video context is recovered separately from EDF annotations and is used only for the fixed context-analysis cohort defined in `analysis_specification/context_analysis_cohort.csv`.
