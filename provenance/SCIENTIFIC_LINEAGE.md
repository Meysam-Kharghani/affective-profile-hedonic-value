# Scientific lineage

1. The analysis began from the public EmoEEG-MC behavioral and EEG data.
2. A data-integrity audit identified a mismatch between raw behavioral row order and reordered nominal stimulus/category labels.
3. Stimulus and category labels were reconstructed for `sub-01` through `sub-53` from participant-specific published sequences and the paired three-trial block design.
4. A common complete-case rule yielded 2,225 core trials from 53 participants.
5. Core representation, held-out-stimulus, double-holdout, within-participant, and dimensionality analyses were executed on the reconstructed labels.
6. Imagery/video identity was recovered independently from EDF annotation TypeIDs and the paired-block design.
7. Forty-five participants met the context-recovery criteria and define the fixed context-analysis cohort.
8. Cross-context transfer, split-half stability, relative bidirectionality, and model-implied surface analyses were run on that cohort.
9. Personalization was evaluated on the core cohort against the global affective-plus-nominal comparator using the fixed support rule.
10. Public results are limited to aggregate evidence; participant-level derived outputs are not redistributed.
