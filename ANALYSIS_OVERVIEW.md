# Analysis overview

## Core representation analysis

Core analyses use 53 participants and 2,225 common complete-case trials. The main comparison evaluates an intercept baseline, an emotion-category model, an eight-report continuous affective profile, and the affective profile with nominal information.

The category-only model is substantially informative, while the continuous affective profile provides higher reconstruction accuracy for both valence and liking. The advantage remains under held-out-stimulus evaluation, simultaneous participant-and-stimulus holdout, and within-participant centering.

## Dimensionality

Valence is close to saturated by affect balance. Liking retains a reliable incremental advantage for the full eight-report profile, indicating a richer multidimensional structure for liking than for valence in these data.

## Context-dependent analyses

Context-dependent analyses use the fixed 45-participant cohort defined in `analysis_specification/context_analysis_cohort.csv`. This cohort contains 1,890 trials, with 945 imagery and 945 video trials.

Cross-context reconstruction remains substantial in both imagery → video and video → imagery transfer. The fixed MAE asymmetry decision rule does not support a directional advantage.

At the family level, affect–hedonic coupling and dispersion show stronger split-half stability than category-specific valuation or the global context contrast. Relative bidirectionality and model-implied surfaces are descriptive secondary analyses.

## Personalization

The personalization procedure compares participant-specific calibration models with the global affective-plus-nominal comparator on identical held-out test trials. The fixed support rule was not satisfied for either outcome.

## Analysis not included in current inference

The context-by-category saturated nominal comparator is not used for any current conclusion.
