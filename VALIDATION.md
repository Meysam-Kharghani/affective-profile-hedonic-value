# Validation status

The public repository is checked for the following conditions:

- reconstructed stimulus/category labels use the documented paired-block design;
- the core cohort contains 2,225 common complete-case trials from 53 participants;
- leave-one-participant-out, held-out-stimulus, double-holdout, within-participant, and dimensionality analyses are represented in the aggregate results;
- the fixed context cohort contains 45 participants and 1,890 trials, with 945 imagery and 945 video trials;
- cross-context transfer results are present for both outcomes and both transfer directions;
- split-half stability, relative bidirectionality, and model-implied surface summaries are present;
- personalization results are evaluated against the global comparator using the fixed support rule;
- public documentation contains no absolute paths tied to a particular computer;
- public documentation distinguishes within-dataset generalization from external validation.

Scientific status of the reported results:

- cross-context transfer is supported in both directions for both outcomes;
- the participant-level MAE asymmetry test does not support a directional advantage;
- the fixed incremental-personalization support rule is not satisfied for either outcome;
- the context-by-category saturated nominal comparator is not included in current inference.
