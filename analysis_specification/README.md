# Analysis specification

`analysis_plan.json` defines the final analysis cohorts, models, validation regimes, personalization gate, and interpretation boundaries used for the public results.

`context_analysis_cohort.csv` defines the fixed participant set used for context-dependent analyses and records exclusions without using behavioral outcomes.

`data_integrity_record.json` documents the nominal-label alignment issue, the reconstruction procedure, context recovery, and the final cohort sizes.

Decision rules described as fixed in this repository were set before evaluation of the corresponding held-out results. This terminology does not imply prospective preregistration.
